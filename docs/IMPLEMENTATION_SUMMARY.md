## 🚀 Как использовать

### Анализ текущего состояния
```bash
cd /agent/repos/tenerifly
node scripts/analyze-apartment-locations.js
```

### Обновление районов в базе данных
```bash
node scripts/update-apartment-districts.js
```

**⚠️ Важно**: Скрипт обновляет данные в Strapi! Перед запуском:
1. Проверьте результаты анализа
2. Убедитесь в корректности маппинга районов
3. Подтвердите изменения когда скрипт спросит

**Примечание**: API Strapi достаточно медленное (~25-30 секунд на апартамент), поэтому полное обновление 128 апартаментов займет около 60-90 минут.

### Использование в коде

```typescript
import { detectDistrict } from '@/lib/districtDetection';

// Определение района
const district = detectDistrict('Los Gigantes', '');
// Результат: "Santiago del Teide"

// Использование в фильтрах
properties.forEach(property => {
  const autoDistrict = detectDistrict(
    property.location?.city,
    property.location?.address
  );
  
  if (!property.location?.region || property.location.region === 'Tenerife') {
    property.location.region = autoDistrict || 'Tenerife';
  }
});
```
