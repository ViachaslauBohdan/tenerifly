## 📖 Как использовать систему

### Анализ текущего состояния
```bash
node scripts/analyze-apartment-locations.js
```
Покажет:
- Сколько апартаментов имеют города/адреса/районы
- Какие районы можно определить автоматически
- Список проблемных апартаментов

### Обновление районов
```bash
node scripts/update-apartment-districts.js
```
Обновит районы в Strapi после подтверждения.

### В коде TypeScript
```typescript
import { detectDistrict } from '@/lib/districtDetection';

// Определить район
const district = detectDistrict('Los Gigantes', '');
console.log(district); // "Santiago del Teide"

// Использовать в фильтрах
properties.forEach(property => {
  const district = detectDistrict(
    property.location?.city,
    property.location?.address
  );
  
  if (district) {
    property.location.region = district;
  }
});
```
